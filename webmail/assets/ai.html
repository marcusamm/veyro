ChatGPT

Åbn Plugins i ChatGPT i din browser. Vælg + → Add custom MCP server, giv den navnet Veyro Mail og indsæt serveradressen ovenfor. Vælg OAuth med automatisk klientregistrering. Vælg Create as a plugin og godkend adgangen hos Veyro. Muligheden afhænger af dit abonnement og dine rettigheder i arbejdsområdet.

Claude

Vælg Customize → Connectors → Add custom connector i Claude. Indsæt serveradressen, vælg OAuth og Register automatically.

Gemini

Gemini CLI kan bruge serveren fra Danmark. Registrér den i terminalen, og godkend forbindelsen i din browser via /mcp auth veyro.

gemini mcp add --transport http veyro https://mail.veyro.dk/mcp

Googles webapp tilbyder aktuelt brugerdefinerede apps til engelsksprogede, personlige konti i USA for brugere på mindst 18 år med Keep Activity slået til. Her tilføjes adressen under Settings → Connected Apps.
